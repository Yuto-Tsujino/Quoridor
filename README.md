# Quoridor

## 概要
C++ / Visual Studioで制作したボードゲーム「Quoridor」です。  
描画や入力処理には `libOne.h` ライブラリを使用し、ゲームルール、ターン管理、壁の配置、勝敗判定などのゲームロジックを実装しました。

## 使用技術
- C++
- Visual Studio
- libOne.h

## 実装内容
- プレイヤーの移動処理
- 壁の配置処理
- ターン制御
- 勝敗判定
- 盤面状態の管理
- タイトル画面・ゲーム画面の切り替え

## 実行方法
1. `originalGame001.sln` をVisual Studioで開く
3. ビルドして実行する

## 操作方法
- Quoridorの詳しいルールは割愛させていただきます
- タイトルからSpaceキーでゲーム開始
- プレイヤーは「駒を動かす」「壁を設置する」のどちらかができる．Spaceキーでモード切替
- 方向キーで移動．壁の場合はMキーで回転
- 駒，または壁の場所が決まったらEnterキーでターン終了
- 勝敗が決まったらZキーでリスタート

## 工夫した点
- Quoridorのルールに合わせて、プレイヤーの移動や壁配置を管理できるように実装しました。
- ターン管理を分けることで、ゲームの進行状態を扱いやすくしました。
- 盤面や壁の状態をデータとして管理し、勝敗判定に利用できるようにしました。
- タイトル画面とゲーム画面を分け、ゲーム開始までの流れを分かりやすくしました。
